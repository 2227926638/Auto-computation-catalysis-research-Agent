## 3. 代码调整

### 3.1 真实库筛选

在 `EvidenceBuilder` 中新增：

- `source_filters`
- `required_keyword_groups`
- `title_path_required_keyword_groups`
- `max_text_sources`
- `max_csv_sources`
- `max_evidence_per_source`

目的：

- 避免全量 2361 篇 md 和大 CSV 直接淹没问题发现。
- 避免非 Ru-CeO2 论文因正文引用 Ru/CeO2 而被误纳入核心文献。
- 让 Markdown 正文优先于 CSV 性能表进入证据抽取。

### 3.2 化学文本归一

新增对常见 PDF/Markdown 转换产物的归一：

- `CeO<sub>2</sub>` -> `CeO2`
- `$CeO_2$` -> `CeO2`
- `N<sub>2</sub>` -> `N2`
- `NH<sub>x</sub>` -> `NHx`
- `Ce<sup>3+</sup>` -> `Ce3+`

### 3.3 参考文献截断

正文读取时在以下段落前截断：

- `ASSOCIATED CONTENT`
- `AUTHOR INFORMATION`
- `REFERENCES`

目的：

- 减少参考文献列表中的 DOI、标题和引用句子污染证据表。

### 3.4 问题生成多样性

将问题生成从：

```text
每个 topic 生成所有 pattern
```

改为：

```text
每个 pattern 轮询所有 topic
```

目的：

- 避免早期 topic 把 20/48 张卡片全部占满。
- 保证 oxygen vacancy、hydrogen poisoning、rate-determining step 等后续 topic 有机会进入候选问题。

### 3.5 推荐列表多样性

在 `QuestionReviewer` 中新增：

- topic priority bonus
- top recommendations 主题去重

目的：

- 避免推荐前 5 全是同一主题的不同变体。
- 保证推荐结果更像“创新点雷达”，而不是单主题改写器。

## 7. DOI/期刊元数据与相似论文获取

用户当前没有 DOI、期刊元数据和近 5 年相似论文数据，因此新增在线增补模块：

```text
src/catalysis_question_agent/metadata_enricher.py
```

数据源：

- Crossref REST API：按 DOI 或题名补全 DOI、期刊、年份、作者等元数据。
- OpenAlex Works API：按推荐问题检索近年相似论文候选。
- Semantic Scholar Graph API：已预留为后续可选源，当前未默认启用。

配置位置：

```yaml
metadata_enrichment:
  enabled: true
  max_sources: 32
  min_confidence: 0.55
  source_types:
    - "local_text"

similar_work_search:
  enabled: true
  max_questions: 5
  max_results_per_question: 8
  from_year: 2021
  to_year: 2026
```

最终联网调试命令：

```powershell
python run_agent.py --config 06_config_real_ammonia_library.yaml --output outputs\real_ammonia_with_metadata_final
```

最终联网输出目录：

```text
outputs\real_ammonia_with_metadata_final
```

新增输出：

```text
metadata\enriched_metadata.csv
metadata\similar_works.csv
metadata\metadata_enrichment_report.md
```
