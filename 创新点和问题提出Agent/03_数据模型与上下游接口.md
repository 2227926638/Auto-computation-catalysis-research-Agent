### 2.2 EvidenceItem


## 3. 下游接口

### 3.1 给纯计算可验证性判别 Agent

传递字段：

- `question_id`
- `title`
- `reaction`
- `catalyst`
- `unresolved_gap`
- `computational_path_hint`
- `expected_result_types`
- `minimal_publishable_results`
- `preliminary_computability`
- `calculation_cost`
- `evidence_links`

期望下游返回：

- `computability_label`: C0/C1/C2/C3
- `claim_boundary`
- `required_calculations`
- `unanswered_by_computation`
- `risk_level`

### 3.2 给新颖性与期刊匹配 Agent

传递字段：

- `question_id`
- `title`
- `question_type`
- `novelty_risk`
- `supporting_sources`
- `similar_work_candidates`
- `graduation_value`
- `target_journal_type`

期望下游返回：

- `novelty_score`
- `competing_papers`
- `target_journals`
- `A/B/C档预估`
- `submission_risk`

### 3.3 给计算规划 Agent

传递字段：

- `reaction`
- `catalyst`
- `candidate_active_sites`
- `adsorbates`
- `reaction_intermediates`
- `computational_path_hint`
- `minimal_publishable_results`

期望下游返回：

- `calculation_task_tree`
- `model_requirements`
- `software_recommendation`
- `minimal_calculation_set`
- `enhanced_calculation_set`
