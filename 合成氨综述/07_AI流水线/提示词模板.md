# 提示词模板

以下提示词用于后续让 Codex/LLM 整理文献和写作。使用前请替换方括号内容。

## 1. 文献矩阵抽取

```text
请从以下文献全文/摘要中提取合成氨综述所需字段。

要求：
1. 不要编造不存在的信息。
2. 如果字段无法从文本中确认，填写 unknown。
3. 区分实验观察、作者推断和 DFT 结论。
4. 输出 CSV 行，字段与 literature_matrix_template.csv 一致。

文献：
[粘贴文本或提供文件路径]
```

## 2. 机制证据抽取

```text
请从以下文献中抽取与 [oxygen vacancy / hydrogen poisoning / Ru cluster / B5 site / EMSI / SMSI / N2 dissociation / NHx hydrogenation] 相关的证据。

每条证据输出：
- evidence_text
- evidence_type: experiment / kinetics / characterization / DFT / microkinetics / review_opinion
- claim_summary
- confidence: high / medium / low
- needs_manual_check: true / false

禁止从参考文献列表抽取证据。
```

## 3. Claim/GAP 合成

```text
基于以下 evidence table，请总结：
1. 领域共识。
2. 仍有争议的问题。
3. 可以写成 critical review 主线的 gap。
4. 哪些 gap 可以导向后续 DFT/微观动力学/实验验证。

输出 claims_and_gaps_template.csv 格式。
```

## 4. 综述大纲生成

```text
请基于以下候选主题和证据矩阵，生成一份 critical review 大纲。

要求：
1. 大纲必须围绕一个中心论点。
2. 每一节都列出需要支持的 claim。
3. 每个 claim 后列出 evidence_id。
4. 标注适合做成图或表的内容。
5. 不要写成普通材料罗列。

候选主题：
[主题]
```

## 5. 分章节写作

```text
请根据以下大纲和 evidence bundle 写 [章节名]。

要求：
1. 学术英文。
2. 每段只表达一个核心论点。
3. 每个机制 claim 后保留 [evidence_id/source_id] 占位。
4. 区分 direct observation、author inference 和 review interpretation。
5. 不要虚构引用和数据。
6. 段末给出 critical synthesis，而不是简单总结。
```

## 6. 审稿风险检查

```text
请以审稿人视角检查以下章节：
1. 哪些论断证据不足？
2. 哪些地方像普通堆文献？
3. 是否有不公平性能比较？
4. 是否混淆实验和 DFT？
5. 是否需要补充经典文献或近三年文献？
6. 给出按优先级排序的修改建议。
```
